The @taiga-ui/mcp Model Context Protocol (MCP) server gives AI assistants structured, on-demand access to Taiga UI — full documentation plus ready-made Angular examples, served from the live source. It is the fastest way to keep an agent aligned with the version you actually have installed.

  • Docs + code snippets: full Taiga UI documentation in Markdown plus ready Angular examples, all in one place.
  • Configurable and lightweight: swap the source URL (stable or next ) without installing Angular locally.
  • get_overview — call this first: the structured documentation header as JSON, with the import map, code-generation checklist, CDK types, common mistakes, and getting-started guides.
  • get_list_components — list all documentation section IDs (with optional fuzzy filtering) plus basic metadata (category, package, type).
  • get_component_example — return the full documentation and code snippets for the requested section names.
  • get_migration_guide — return the complete migration guide for version updates: checklist, schematics steps, snippets, and troubleshooting.
