Three habits that keep AI-generated Taiga UI code correct as the library evolves.

  • Compiles ≠ works. A green build is necessary, not sufficient — the most expensive Taiga mistakes stay invisible until the page renders (or refuses to). Run the app.
  • Prefer the live, version-correct API over the model's memory. Symbols move between packages across majors; llms-full.txt and the MCP server always reflect the version you have installed.
  • Keep durable and volatile knowledge apart. Method in the skill; exact names, packages, and options from llms.txt / MCP — so the guidance can't rot as the library evolves.
