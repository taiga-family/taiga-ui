tui-developer

A skill focused on building with Taiga UI — the architecture, the setup order, the categories of mistakes agents make, and one firm rule: consult the live source before writing markup. It keeps only stable knowledge and delegates volatile specifics — exact names, packages, per-symbol options — to llms.txt and the MCP server.
