llms.txt is a proposed standard that helps LLMs understand and process a site's content. We generate two always-fresh flavours so tools that lean on LLMs for code generation produce better Taiga UI code.

  • llms.txt — a table-of-contents file with links to the key resources.
  • llms-full.txt — a detailed, compiled set of resources describing how to build with Taiga UI, with component examples.

Paste llms-full.txt straight into your model's context for a zero-setup start, or point any llms.txt-aware tool at the hosted URL so it always reads the current, version-correct API.
