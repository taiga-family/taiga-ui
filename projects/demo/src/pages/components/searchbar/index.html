TuiSearchbar is a mobile search field. Project a native <input tuiSearch> on its own to get an inline field, or add a <button tuiButton> — the searchbar lays them out per platform: on iOS the button sits to the right of the field, on Android it moves inside the field on the leading side.

@for (example of examples; track example) { @switch ($index + 1) { @case (3) { An active field on iOS is floating : liquid glass with a round cancel button. } @case (4) { Pinned along with the app bar, the field is floating from the start and keeps that look while the content scrolls under it. Pinning is up to you, the searchbar only takes care of the look. Once the field becomes active, it takes the place of the app bar } @case (5) { Under a large heading the field starts inline and turns floating once the heading scrolls away — here the switch is driven by an IntersectionObserver watching the heading } @default {} } }
