# Shadows

Different kinds of shadows can be applied with css variables:

Basic shadow:
`--tui-shadow`
with
`--tui-shadow-small-hover`
when hovered

Dropdown shadow:
`--tui-shadow-medium`

Modal shadow:
`--tui-shadow-popup`

Sidebar shadow:
`--tui-shadow-medium`

Navigation shadow:
`--tui-shadow-small`

Mobile modal shadow:
`--tui-shadow-popup`
